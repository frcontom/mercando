# MASTER
## Smart Market Planner

Documento maestro del proyecto.

### Objetivo
WebApp Mobile First para planificar mercados mensuales usando Angular + Supabase.

### Stack
- Angular
- Supabase
- TailwindCSS
- Angular Material
- Signals

### Principios
- Mobile First
- Arquitectura limpia
- Componentes reutilizables
- Sin autenticación (password local: 6501)
- Preparada para PWA
